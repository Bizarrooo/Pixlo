# Pixlo

A customizable creator-profile prototype built with Next.js.

## Run it

Open this folder in VS Code. Use **Command Prompt** rather than PowerShell if Windows blocks `npm.ps1`.

```cmd
npm install
npm run dev
```

Open `http://localhost:3000/dashboard` to customize the profile.

## Included

- Responsive public profiles and dashboard
- Username-based profile routes
- Image, video and audio uploads stored locally in IndexedDB
- 500MB background-video limit
- Music library with track names, artists and custom cover art
- Automatic audio playback attempts with browser autoplay limitations respected
- Independent profile opacity and text opacity
- Background positioning, scaling, blur, overlay and vignette
- Card, avatar and banner controls
- Social links and layouts
- Motion, particles, grain, scanlines and glow effects
- Multiple profile layouts
- Local browser view counter

This is still a local/browser prototype. A production multi-user site needs authentication, a database and object storage for permanent media.
